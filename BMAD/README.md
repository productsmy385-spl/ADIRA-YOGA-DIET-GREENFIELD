# BMAD Workspace — Yoga Therapy & Wellness Platform

This folder contains the BMAD planning and execution workspace for the greenfield Yoga Therapy & Wellness Management Platform.

## Mandatory source of truth

- `/docs/KNOWLEDGE-BASE.md` — what the product must be
- `/BMAD/` — how the product is analyzed, planned, designed, implemented, tested, reviewed, and deployed
